## 1. 落地

### 1.1 MCP 与技能进人格闸

- `PLUGIN_IDS` 加 `mcp`；`compose_registry` 里 `plugin("mcp") && config.mcp.enabled`。
- `persona.toml` 的 `[plugins]` 新增两条白名单：`skills = [...]`（非平台级技能按名字）、
  `mcp = [...]`（服务器按 id，在拉 tools/list **之前**过滤，关掉的服务器不会被拉起）。
  三条白名单（scripts/skills/mcp）全开时都不落盘（None = 全部，之后装进来的自动可见）。
- 技能白名单在 `skills::discover` / `load` / `catalog_fingerprint` 三处同步生效
  （指纹算进白名单，改清单即失效催化缓存）；skill-creator / script-creator 永远放行。
- 成员：`mcp`、`knowledge_base`、`web_images`、`scripts` 进成员常开集（今天成员本就能用 MCP）。

### 1.2 引导（`src/oobe/`）

- 入口：裸 `miyu` 且 `config.oobe_done == false`，或 `miyu oobe`。`miyu init` 保持非交互、
  **不**标记完成——脚本部署的机器上第一次由人打开 TUI 照走引导，装好的 shell hook 显示「已经装了」。
- 老配置：`config_version` 2→3，迁移里 `oobe_done = true`，老用户不被拦。
- 五屏：人格（内置 Miyu / 自己捏：名字 + 可留空的提示词）→ 功能（`feature_catalog`，双列勾选）
  → 认识你（`profile.md`）→ 终端集成（探到的 shell，已装的标「保持」）→ 接模型
  （借 claude / codex / agy 订阅、opencode Zen、填 key、进设置界面）。每屏「下一步」即落盘。
- 接模型放最后，CLI 目录（最长 20s）在前四屏期间后台预拉；claude 走预置表瞬开。
- 收尾不做完成页、也不自动发一轮对话（会让会话立刻非空、看不到 banner）：接模型那步
  拉模型列表即验通。跳过（Ctrl+S）只置 `oobe_done`。开场 Esc/Ctrl+C 什么都不写。
- `feature_catalog`（`src/config/feature_catalog.rs`）是终端与 WebUI 成员引导共用的真相源。

### 1.3 空会话 banner 与 Tab

- `src/terminal/{palette,starfield}.rs`：色深四档降级（真彩/256/16/无色，`MIYU_COLOR`/`NO_COLOR`/`MIYU_ASCII`）、
  星空哈希、渐变艺术字、扫光——引导与 banner 共用。
- `src/cli/repl/banner/`：`BannerScene` 只产片段行；全屏后端把它铺成「大厅」（见 §4 第 10 条），
  inline 后端塞在输入框上方（终端太矮不挂）。80ms 空闲 tick 驱动，星空 160ms 一帧，扫光每 7s 一次。
- 可替换：`config/banner.txt`（首行可 `subtitle: …`，`# ` 注释），`display.banner = false` 关掉。
- Tab：`LiveReplEditor.mode_switchable` 只在会话空时为真 → `LiveReplOutcome::SwitchMode`；
  `switch_repl_lane` 取另一车道当前会话，非空则新开一条（保证 banner/Tab 可逆）。
  第一条消息（非斜杠）发出即撤 banner、钉死模式；`/new`、`/reset` 后又回来。
- 直连模式（`MIYU_DIRECT=1`）在第一轮之前走的是旧输入框，没有 banner；Tab 换车道在第一轮后的 live 输入框里有效。

## 9. rebase main（09-14）

main 同期合进了全屏 TUI 的两批（`/new` 清屏并回放目标会话、配置向前兼容读 `extra`、
面板/转轮/链接）。四处冲突的合法：

- `input.rs` 轮询间隔：面板开着**或**大厅挂着都放到 40ms；
- `session.rs` 换会话：目标非空时不再「顶出视口」（正文顶部对齐之后回放会缩在屏底），
  改成 `LiveReplTail::wipe_transcript` 整个丢掉再回放到屏顶；目标为空的画布在
  `set_session_empty` 里已经丢过；`/new` 的「已切换到会话」在大厅里是一条通知；
- `config/mod.rs` `DisplayConfig`：`banner` 与 `extra`（flatten）并存，`banner` 放前面；
- `timeline.rs` 图标：deep_research/check_issue 那组删掉，archwiki/archlinux_news 走 main 的 Arch 标。

顺手：全屏大厅每 40ms 那一帧原来没裹同步块（输入框先擦后写，pyte 与真终端都能撞见半帧），
`tick_banner` 全屏支现在一帧一个同步块。`testkit/tui/round26.py` 的 `/new` 判据改成到字节流
里找通知；它要 `LANG=zh_CN.UTF-8`（systemd user manager 是 en_US，裸 `systemd-run` 跑出来全英文）。
