# Miyu 使用与开发文档

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 Miyu 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `miyu -h`、`miyu config`、仓库 README 及源码为准。

**Miyu 是什么？** 一句话：Miyu 是一个“活在终端里的二次元少女”——开箱即用的开源 AI 助手。它由大模型驱动，能在终端里陪你聊天、查资料、修系统、玩游戏；也能接入 WebUI 和 QQ，远程帮你操作电脑、管理群聊。

本目录是面向普通用户的参考文档，用说人话的方式解释 Miyu **能做什么、怎么用、怎么设计、怎么参与开发、怎么扩展和修改**。文档按主题拆分，从下面这张地图开始即可。

## 30 秒上手

```bash
# Arch Linux
yay -S miyu

# 第一次运行（自动初始化）
miyu

# 或者显式初始化
miyu init

# 开始聊天
miyu normal     # 普通模式：完整人格和全部能力
miyu dev        # 开发模式：极简，专注写代码/干正事
```

> Miyu 默认使用 opencode 的公共模型服务，开箱就能聊；但公共额度有限且可能波动，建议运行 `miyu config` 配置自己的 API。

## 约定

- 文档以 Miyu 0.4.x 代码为基准。
- `~/.miyu` 是默认数据根目录，可用环境变量 `MIYU_HOME` 改位置。
- Miyu 的“工具”不是给你在终端里敲的命令，而是 **AI 在对话中自己决定调用** 的能力；你只需要用自然语言说“帮我查天气/搜图/设个闹钟”。
- 涉及真实文件删除、安装软件等操作时，Miyu 有安全护栏（详见 [16-安全与隐私](16-安全与隐私.md)）。
