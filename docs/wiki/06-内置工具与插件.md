# 06 · 内置工具与插件

> ⚠️ **临时版本提示**：本文档由 DeepSeek 根据当前 Miyu 源码逐行整理，属于临时参考版本；正式版文档仍在施工中，内容可能与最新代码存在出入。请以 `miyu -h`、`miyu config`、仓库 README 及源码为准。

## 先理解“工具”是什么

Miyu 的工具不是给用户敲的 CLI 命令，而是**给模型看的功能说明书**。你说“帮我查天气”，模型判断需要调用 `get_weather`，Miyu 执行工具并把结果喂回模型，模型再用大白话回答你。

例外：`miyu tool-call` 可以让你直接从终端调用这些工具。

## 工具注册的三套清单

| 场景 | 工具集 |
|---|---|
| Normal 模式 | 完整工具：网络、文件、命令、知识库、记忆、娱乐、Arch/Linux 等 |
| Dev 模式 | 极简：run_command、jobs、apply_patch、todo、task、web_fetch，以及开关打开后的 web/vision/memory/MCP |
| QQ 等受限平台 | 只读网络工具为主；**没有** shell/本地文件/记忆/知识库/MCP/脚本；唯一写工具例外是生图 |

## 工具如何注册与懒加载

- 每个工具有：`name`、`description`、参数 JSON Schema、`permission`（ReadOnly / Presentation / Writes）、`always_loaded`、`load_policy`、`groups`、`timeout_seconds`。
- 描述以 `src/tools/descriptions/*.json` 为唯一真相；Rust 代码里的描述只是占位，注册时被 JSON 覆盖。
- 默认加载模式 `stub`：懒工具全部以“真名 + 一句话摘要 + 宽松参数壳”常驻工具目录。模型要用完整参数合同时调 `load_tools`，工具结果在对话尾部返回——这是为**前缀缓存命中**做的设计（见 [10-系统设计与架构](10-系统设计与架构.md)）。
- `load_tools` 按组加载；未知名一票否决；`Summary` 策略的懒工具允许未加载直接调用，`Group` 必须组加载，`Hidden` 不能经 load_tools 加载。

## 重要工具详解

### run_command：怎么保证安全

- 用 `sh -lc` 执行，cwd 为会话工作区。
- 独立进程组，超时/取消用 killpg 杀整组。
- 输出流式读取，8 MiB 硬上限；展示端裁剪 20k 字符，保留头部 + 尾部。
- 配置 `tools.command_deny` 提供子串黑名单；`skills.allow_command_execution` 关闭后拒绝执行命令。
- 提示词要求：装/卸软件前必须问用户；删除数据前先列清单并确认，默认进回收站。

### apply_patch：主力编辑工具

- 支持 Add/Update/Delete File 补丁。
- 解析严格：`@@` 必须、hunk 行数校验；无锚点 hunk 多匹配直接拒绝。
- 匹配四级兜底：Exact → TrimEnd → Trim → 全角/弯引号/NBSP 归一化。
- 写入原子化（临时文件 + persist），并给终端显示 unified diff。
- Artifact 目录额外防 symlink 逃逸。

### check_issue：只读取证的系统诊断

参数：`query`、`area`（auto/system/app/input_method/display/audio/package/gpu/network/storage）、`target`、`depth`（quick/normal/full）、`recent_minutes`、`platform`、`allow_launch_probe`。

- 自动从“打不了中文”“没声音”“显卡驱动”等关键词推断 area。
- Linux 覆盖最全：环境变量、`uname`、pgrep、systemctl user 服务、journal、`/proc/pid/environ`、Wayland/输入法模块、lspci、`ip -brief addr`、`df -hT` 等。
- 隐私：`$HOME` 替换为字面 `$HOME`，IP/MAC 打码，journal 最多 80 行。
- `quick` 跳过 journal；`normal` 与 `full` 当前等价。
- 只读取证，不修改系统；`allow_launch_probe=true` 才会短暂启动目标应用采样后 kill。

### 游戏兼容性工具

- `protondb_query`：Algolia 反查 AppID + 官方 reports API；输出 tier/confidence/score 和玩家报告（tier、faults、Proton 版本）。
- `query_caniplayonlinux`：解析游戏列表与详情页，输出 verdict、native/Proton、反作弊、Steam Deck、已知问题等。
- 技能 `linux-game-compatibility` 引导模型组合 ProtonDB + Are We Anti-Cheat Yet? + Can I Play On Linux 综合判断。

## 工具权限与护栏

- 权限分 ReadOnly / Presentation / Writes。受限平台除生图外全部只读。
- 守卫（guard）只拒不放：例如同一轮里先审查后立刻安装 AUR 包会被拦截；命令黑名单。
- QQ 群聊的宿主工具（发消息、@人）只有管理员能用；私聊需白名单 + `allow_non_admin_host_tools` 才放行。
- 文件读取限 50 KiB / 2000 行 / 单行 2000 字符；平台文件读取限 128 KiB。
- 删除文件默认走回收站（`trash_path`），拒绝 `/`、家目录、工作区根、Trash 自身等 15 类危险路径。
