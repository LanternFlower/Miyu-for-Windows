# 空会话大厅：窄框里的换行错位与缩行时的 footer 重影

对应计划 `Miyu-2026-09-14-plan/01-小修复.md` 的 F2。

## 现象

空会话大厅（全屏、banner 挂着）里：

1. 输入一段中文，文字在框右边折了行，**光标却停在框外面的星空上**、还留在
   第一行（用户截图里那根竖条）。上下方向键也跟着跳错行。
2. 删字让输入区从两行缩回一行时，屏幕上**短暂出现两条 footer**（模式 · 模型 ·
   用量那一行）。下一帧星星一动就被盖掉，所以只看静止截图抓不到。

## 根因：一个框，四处各算各的宽度

大厅里输入框不是全宽的，是终端三分之二宽、居中的一个窄框
（`Banner::lobby` 里的 `width`/`left`）。而「这个框有多宽」原本有三个来源：

| 在哪 | 用的宽度 | 后果 |
|---|---|---|
| `tail/frame.rs` 测活动区高度 | 整终端宽 `cols` | 行数少算，整块位置排错 |
| `input.rs` 画字 | 窄框宽 | 折行按窄框（这个是对的） |
| `input.rs` 算光标（`repl_cursor_position`） | 整终端宽 | 光标落到框外、行号偏小 |
| `editor.rs` 上下方向键 | 整终端宽 | 按错误的物理行找落点 |

第二个问题是另一条链。全屏下正文（banner）**按行 diff**：`Screen::painted`
记着「这一行上一帧画的是什么」，一样就跳过。但活动区是 `paint` 之后才打上
去的，`painted` 里记的仍是正文以为自己画了什么。缩行时整块重新居中，新
footer 落到比原来高一行的位置，旧那行既不在新活动区里（编辑器的清行从
`input_row` 起，够不着它），banner 那一行又恰好没变（大厅里输入框那几行的
banner 内容是空的）——diff 判「没变」直接跳过，旧 footer 就留在屏幕上。

inline 那边没有这个病：`redraw()` 先 `suspend()` 把旧活动区整块擦掉。全屏
的 `resume_at_own` 没有这一步。

## 修法

**一、横向几何收成一处**：新增 `src/cli/repl/input_layout.rs`，`EditorBox`
（左边距 + 宽度）是唯一真相，`lobby_box_width` 是唯一的窄框宽度公式，
`Banner::lobby` 也改成调它。

能这么做的前提是**窄框宽度只由终端宽决定，与活动区高度无关**——于是
`resume_at_inner` 可以先定宽、再按这个宽度测行数、最后才让 banner 排纵向
位置，不存在「测高要先知道宽、定宽要先知道高」的循环。测量、绘制、光标、
排队行、上下方向键（`LiveReplEditor::box_cols`，每帧由活动区写进来）现在
全部消费同一个宽度。

**二、擦旧活动区**：`Screen::invalidate_activity_rows(prev, next)` 把「旧活动区
里新活动区盖不到的那几行」在 `paint` 之前标成脏（`painted` 写哨兵 `\0`，
空串不行——空行画出来就是空串，diff 会认为没变，见 `force` 的注释），正文
层照常重画它们，编辑器再画在上面。这是 inline `suspend()` 的全屏版，大厅
和普通全屏会话两条路都走。

**三、收尾光标**：一帧的最后无条件 `MoveTo(input_cursor)`。原来只有「有后台
任务」那条分支才收尾。

## 守着它的东西

- `src/cli/tests/lobby_layout.rs`（11 条）+ `input_layout.rs` 自带 4 条：窄框
  几何、折行与光标一致、活动区高度按框测、旧活动区的脏行。
- `testkit/tui/lobby.py`：真 PTY + pyte 的走查。两处关键：
  - **按绘制交易看屏幕**。TUI 每帧裹在同步更新里（`ESC[?2026h` … `l`），
    测具攒够一整笔才喂给 pyte。按读到的 chunk 边界看会切在半帧上——第一版
    就是这么把光标读成艺术字里的某一格、把输入框读没了的。
    大厅的星星 40ms 动一次、输出永远静不下来，「等静默」在这儿不成立。
  - **逐帧查 footer 条数**。重影只在某一帧上出现，等静止了再看永远是干净的。

修复前跑这份走查：`cursor_inside_box` / `cursor_on_last_text_row` /
`one_footer_after` / `no_duplicate_footer` 四条红，重影在 81 帧上抓到。
