# MCP 工具执行错误被当作成功

状态：2026-09-16 用户验收通过，授权分项提交并合并 main。

Downloads 计划 03 的独立问题清单指出 `format_mcp_result` 可能丢失 `isError`。
核对 MCP tools 规范：JSON-RPC 正常响应仍可用 `isError: true` 表达工具执行失败。
原转换只拼接 content 文本，未保留此标志；Miyu 的结果判定只识别 JSON 的
success/ok 布尔字段，普通文字默认成功，因此错误被误判。

修复只在失败结果外加既有 `{ "ok": false, "error": "…" }` 包装。
原诊断内容保留，成功返回字节不变。没有修改工具 schema、目录、权限、历史或回放。

新增 `src/tools/mcp/result_tests.rs`：文本错误、成功形状的 JSON 错误正文、无文本
错误、多种成功结果，以及真实 stdio 假 MCP 请求链。修前 4 条失败、1 条通过；
修后 MCP 整组 12 条通过。
