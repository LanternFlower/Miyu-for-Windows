# 窄终端 footer 换行与后台状态区闪烁

## 根因

截短模型名的分支漏算运行动画的 8 列（3 个空格与 5 根声波）。48 列终端因此
输出 56 列 footer。溢出片段落入后台任务区，又被状态刷新覆盖，出现闪烁。
SSH 不是必要条件，本地窄 PTY 同样复现。

## 修复

footer 统一按显示宽度计算，先扣除声波和固定字段，再裁切模型名。保留 ANSI
序列与字形簇；对极窄屏补最终上限，尾部补空格，确保局部刷新清掉旧内容。
改动限于 footer，不替换其他界面的宽度计算。

## 回归与验收

`cargo test --lib cli::tests::footer_width`
基线 `85f7dc29` 为 3 红 1 绿，包含 48 列输出 56 列。新用例覆盖 1–160 列、
运行与空闲、普通与开发模式、中文、组合字符和 emoji；用终端布局解析器验证
没有写入下一行，并检查足够宽时输出不变。

人工验收：SSH 连接后缩窄窗口，在前台回复进行中保留一个运行中的后台任务。
观察 footer 保持单行，后台状态区无 token 尾巴闪烁；扩大窗口后信息恢复。
命令名和参数应使用有意限制时长的测试任务，例如 `sleep 30`。
