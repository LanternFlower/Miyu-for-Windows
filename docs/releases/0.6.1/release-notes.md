# Miyu 0.6.1 · 设置界面换了张脸，流程图画成图，DEB 装得上 24.04

这一版的重点是**能看见、能改**：设置界面整个重画成引导那张脸，引导里那张「自选功能」表进了设置；```mermaid 围栏在终端和 WebUI 里直接画成图；报错改成说人话。另外新增 CodeBuddy 供应商，DEB 的支持下限从 Ubuntu 25.10 降到 **24.04 LTS**。

完整的一百多条改动在[更新记录](https://github.com/SHORiN-KiWATA/miyu-agent/blob/v0.6.1/docs/releases/0.6.1/changelog.md)里，下面只挑重点。

## 设置界面重画，功能表进得去了

`miyu config`（和全屏 TUI 里的 `/config`）跟第一次启动的引导界面同一张脸：渐变 MIYU 艺术字、会闪的星空、一道来回扫的光。每一行拆成**名字 + 当前值**两列对齐，banner 下面是面包屑（在第几层一眼看得出），按键提示挪到屏底且放不下会折行——以前一行列不下时被截掉的总是最后那个「返回」。报错会换行、用暖红，不再冲出屏幕右边。**按键一个都没变**，改动仍是退出时一起保存。

主菜单的**「插件配置」和「自定义提示词」合并成一项「人格和功能」**，里面的「启用的功能」就是引导里那张表，而且比引导那张更全（多摆了网络搜索/识图、长期记忆与技能、常开的内置插件）。一行上有两个动作：**空格** = 这个人格用不用它（写人格自己的 `persona.toml`），**回车** = 这台机器上它怎么配（密钥、尺寸、账号）。勾上一行会顺手把机器层的开关也打开——以前勾了却因为机器层关着而不生效，人得在两个菜单之间来回找。

## ```mermaid 围栏画成图

以前她画个流程图给你，你看到的是一坨 `flowchart TD` 源码。现在：

- **终端**：kitty / ghostty 直接把图画在回复里，跟着正文滚动、回翻；其它终端交给 chafa。图下面有一行「点开看大图」，用系统看图器打开矢量原图。
- **WebUI**：图以卡片渲染在输出里，右上角可在图和源码之间切换，点图走灯箱放大。
- 两边共用**同一个纯 Rust 渲染器**（23 种图型），不再需要 mermaid.js，浏览器零第三方脚本。画不出来的那张整块退回带语法高亮的代码块，**永不阻断输出**。画过的图两边都有缓存，回翻和刷新不再重算。

## 新增 CodeBuddy 供应商

和 Claude Code / Codex / Antigravity 一样，借你本机 `codebuddy` CLI 已有的登录态说话，Miyu 不经手任何凭据。模型清单从 `codebuddy -h` 现场解析（16 个），它以后加模型不用等 Miyu 更新。供应商列表里**本机 CLI 中转线现在恒定排在最前**，彼此按字母序。

## 过程显示：三个开关，命令那一步改版

- 显示设置收成**三个正交的开关**：展开思考内容 / 展开工具内容 / 过程收起成 `Worked for …`。原来那两个三值档（隐藏 / 摘要 / 完整）退役。
- **命令那一步改版**：抬头写「这条命令是来干嘛的」，命令本身排在抬头底下（露几行，完整的点开看）；点开之后命令带**语法高亮**，heredoc 按解释器认语言。编辑文件那一步的抬头带上改动量 `+12 -3`。WebUI 的「运行命令」也改成了同一个样子。
- **正在想的时候，「展开思考内容」关着也看得到它在想什么**：抬头底下开一扇滚动窗，露最近几行。
- **内容多了之后不再卡**（长会话里一帧从几十毫秒回到零点几毫秒），改窗口大小时已经在屏上的正文会**跟着重新折行**，拉宽收窄都不掉字。
- 耗时读数加了毫秒档，不到十分之一秒的步骤也有数。

## QQ

- **回复触发条件改成可叠加的集合**：几个窗口同时成立就加几份意愿，不再按「主触发」一档定死。**命中违规关键词不再抢断正在进行的对话**——违规检查成了并行的一面旗子，有社交触发时照常回复。违规词表按真机 38878 条消息实测**砍掉 22 个误报词**（`OD` 中在 `model` 里、`64` 中在 `x86_64`、`盒` 中在「沙盒」），触发量降 88%。
- **好感度终于会动了**：评分规则从五档（且明写「普通交流 0」）换成九档，最常见那档给 0 到 +0.8 的余地。此前实测 1834 次调用几乎全输出 0、187 个人里 165 个停在初始值。
- **历史记录里看得见撤回了**，被管理员撤掉的标成 `(recalled by qq=…)`；查询也**写清了能按时间范围查**，一次给够 500 条（上限抬到 2000），不再把一天切成四段查四次。
- 现在可以让她**把消息发到任意好友或群**（普通模式）：「把这个发到 xxx 交流群」，撞名会报候选让你挑。开发模式仍然只发管理员。
- 「群聊发完消息后观察窗口」有自己的开关了，覆盖窗口从 5 秒延长到 7 秒。

## 子代理与后台任务

- **子代理会话化（后端）**：每个子代理是挂在父会话下的一条真会话（`kind=subagent`），跑普通回合、历史落库，可以再开一层孙代理（不能再往下）。「任务完成」改为「没有活动回合、且名下没有未完成的后台任务」。消耗计进账本，主会话的 Σ 含整棵树。daemon 重启时没跑完的标「已中断」，给它回复就接着跑。
- 子代理浮层和后台任务面板补齐了十几处：浮层里的字**选得动、复制得走**，编辑那一步有 diff 和 `+3 -1`，每个工具都有耗时，思考逐字跟着走，并且终于**跟着那三个显示开关走**。

## 命令与新开关

- **`/dev` 与 `/normal`**：切到那条车道上的会话；`/session` 列表把普通、开发两侧合并列出，当前车道排前。新增全局设置「终端集成会话默认模式」。
- **`miyu` 和 `miyu dev` 现在打开一条新会话**，不再接着上次那条聊（要接着用 `/session`）。
- **她说话的时候斜杠命令不再一律失灵**；回合中开 `/models` `/session` 直接嵌在回合里跑，思考不再被切成好几行小结。
- **`/goal` 跑着时输入框右上角常驻一行** `/goal running · 第 3 轮 · 12s`，停下来写 `paused`、受阻写 `blocked`。
- **`/sandbox <路径> --allow-read` 多了「只锁写」这一档**；`/variant` 改名 **`/effort`**（旧名保留为别名）。
- **桌面通知会响一声了**，在 kitty 里还能点通知跳回发它的那个窗口。新增「通知带提示音」「提示音文件」开关。
- **shell 集成会跟着 Miyu 一起升级**（hook 顶上带版本与指纹，五道闸保证不乱改你的 rc）。
- **同一个会话可以开两个终端界面**，两边看到的是同一份实况。
- WebUI：聊天正文里**选中文字右键** → 解释 / 翻译 / 引用追问 / 搜索 / 复制；解释按你界面的语言回答。表格里可以用 `<br>` 换行。
- 在 [herdr](https://herdr.dev/) 里开 Miyu，侧栏会显示她在干什么。

## 挑几条修复

- **模型报错改成说人话**：分七档说事（限流/额度、认证失败、没这个模型、请求被拒、内容策略…），带上该端点要停多久、供应商自己那句话，不再是一行英文模板加一坨原始 JSON。claude-code / codex / antigravity 三条 CLI 中转线不再谎报「HTTP 429」。
- **后台不再攒下一堆 `miyu` 僵进程**：起 daemon 的那个进程没了，daemon 跟着退出（`PR_SET_PDEATHSIG`）；Miyu 自己启动的后台服务不受影响。
- **Antigravity 被内容策略拦下一句之后，整条会话不会再跟着哑掉**；额度错误也不再让她对某些人长时间一句不回。
- **opencode Zen 的免费模型又能用了**（它 09-19 起按请求体里的工具名放行，Miyu 发往 Zen 系端点时会换成它认得的写法）。
- **会话钉的模型被下架或改名之后自动退回全局模型池**，不再把这条会话锁死、连 `miyu` 都进不去。
- **QQ 群里她的引用时灵时不灵**——是对端（SnowLuma 1.14.7）自己发负数消息号又拒收，现在这种情况不会再悄无声息。
- 终端里说话带通配符不再被 fish / zsh 吞掉；她不能再用 `rm` 删东西了（按命令位判，`dev` 模式同样拦）。

## 升级注意

- ⚠️ **要 `miyu daemon restart`**（子代理会话化、QQ 那一批、报错文案都在 daemon 侧）。已经开着的终端要重开才用新前端。
- ⚠️ 原本靠关掉「自然续聊」来一并关掉观察窗口的配置，升级后**观察窗口会重新打开**，要单独关。
- ⚠️ 手改过表情包搜索条数（原默认 1、上限 3）的配置文件不会自动变，建议自己改成 5。
- ⚠️ 人格功能清单的改动**要她下一轮才读到**（工具面是每轮按清单构造的）。
- **DEB 的支持下限降到 Ubuntu 24.04 LTS**：以前 24.04 装不上（`libc6 (>= 2.41)` 不满足），门槛其实是构建基座定的——现在基座换成 `ubuntu:24.04`（glibc 2.39），包里的下限跟着基座走。**从这一版的包开始生效。**

## 下载与安装

附件仅提供 **Linux x86_64** 的六个安装包。主包自带字体、语义模型、表情、脚本、默认知识库和许可证；语音为可选包，需要与主包相同修订。已装语音的用户请在同一条安装命令里同时指定两个包。

| 发行版 | 主包 | 可选语音包 |
| --- | --- | --- |
| Arch Linux | `miyu-0.6.1-1-x86_64.pkg.tar.zst` | `miyu-voice-0.6.1-1-x86_64.pkg.tar.zst` |
| Debian 13 / Ubuntu 24.04 LTS 及更新 / Linux Mint 22 | `miyu_0.6.1-1_amd64.deb` | `miyu-voice_0.6.1-1_amd64.deb` |
| Fedora 44 | `miyu-0.6.1-1.fc44.x86_64.rpm` | `miyu-voice-0.6.1-1.fc44.x86_64.rpm` |

```bash
# Arch Linux
sudo pacman -U ./miyu-0.6.1-1-x86_64.pkg.tar.zst

# Debian / Ubuntu / Linux Mint
sudo apt install ./miyu_0.6.1-1_amd64.deb

# Fedora 44
sudo dnf install ./miyu-0.6.1-1.fc44.x86_64.rpm
```

这六个包这一轮在 **Arch、Debian 13、Ubuntu 24.04、Ubuntu 26.04、Linux Mint 22.3、Fedora 44** 的干净容器里逐个真实安装，并各自跑通了一次真实模型回复。Arch 用户也可以走 AUR 的 `miyu` / `miyu-voice`（二进制包装）或 `miyu-git`（源码构建）。
