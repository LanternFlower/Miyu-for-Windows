# Miyu 0.6.1

设置界面重画了一遍，跟第一次启动的引导是同一张脸；引导里那张「自选功能」表以前走完就再没有入口，现在挂在设置里，而且比引导那张全。她画的流程图不再吐一坨 `flowchart TD` 源码，终端和 WebUI 都直接出图。模型报错改成了人话。另外新增 CodeBuddy 供应商，DEB 的支持下限从 Ubuntu 25.10 降到 24.04 LTS。

一百多条改动的完整记录在[这儿](https://github.com/SHORiN-KiWATA/miyu-agent/blob/v0.6.1/docs/releases/0.6.1/changelog.md)。

## 设置界面

`miyu config`（全屏 TUI 里是 `/config`）现在是渐变的 MIYU 艺术字加会闪的星空，居中那个 `┌─ MIYU 配置 ─┐` 框没有了。每一行拆成名字和当前值两列，banner 底下是面包屑，按键提示挪到屏底、一行放不下会折到第二行——以前被截掉的总是排在最后的那个「返回」。拉模型失败时那种一长串报错会按正文宽折行，用暖红。按键一个都没变，改动仍然是退出时一起保存。

主菜单的「插件配置」和「自定义提示词」合成了一项「人格和功能」。里面的「启用的功能」就是引导里那张表，另外多摆了网络搜索、识图、长期记忆与技能，还有那些常开的内置插件。一行上有两个动作：空格管「这个人格用不用它」，回车管「这台机器上它怎么配」——密钥、尺寸、账号那些表单，现在挂在对应那一行上。勾上一行会顺手把机器层的开关也打开，因为两层都开着工具才挂得上；以前勾了却不生效，人得在两个菜单之间来回找。

## mermaid 画成图

围栏语言写 `mermaid` 就会渲染。kitty 和 ghostty 把图直接画在回复里，跟着正文一起滚动、回翻；别的终端交给 chafa。图下面有一行「点开看大图」，点一下用系统看图器打开矢量原图。WebUI 那边是卡片，右上角能在图和源码之间切，点图走灯箱放大。

两边共用同一个纯 Rust 渲染器，23 种图型，不再需要 mermaid.js，浏览器零第三方脚本。画不出来——终端不认图形协议、语法有硬错误、图型不支持——就退回那个带语法高亮的代码块，绝不吞掉输出。画过的图两边都有缓存，回翻和刷新不会重算。

## CodeBuddy

和 Claude Code / Codex / Antigravity 一样，借你本机 `codebuddy` CLI 已有的登录态说话，Miyu 不经手任何凭据。模型清单从 `codebuddy -h` 现场解析，一共 16 个，它以后加模型不用等 Miyu 更新。顺带把供应商列表理了一下：本机的 CLI 中转线恒定排在最前，彼此按字母序，不再是每加一条就改一次硬编码。

## 终端里的过程

显示设置收成了三个互不相干的开关：展开思考内容、展开工具内容、过程收起成 `Worked for …`。原来那两个三值档退役了。

命令那一步换了版式。抬头写这条命令是来干嘛的，命令本身排在抬头底下，露几行，完整的点开看；点开之后命令带语法高亮，heredoc 按解释器认语言。编辑文件那一步的抬头带上了 `+12 -3`。WebUI 的「运行命令」也改成了同一个样子。

她正在想的时候，「展开思考内容」关着也看得见她在想什么了——抬头底下开一扇滚动窗，露最近几行。

内容多了之后不再卡：长会话里一帧从几十毫秒回到零点几毫秒。改窗口大小时，已经在屏上的正文会跟着重新折行，拉宽收窄都不掉字。耗时读数加了毫秒档，不到十分之一秒的步骤也有数了。

## QQ

回复触发改成了可以叠加的条件集合，几个窗口同时成立就加几份意愿，不再按一档定死。命中违规关键词也不再抢断正在进行的对话——判官本来就在查违规，有社交触发时她照常回复。违规词表按真机 38878 条消息砍掉了 22 个误报词：`OD` 会中在 `model` 和 `code` 里，`64` 中在 `x86_64`，`盒` 中在「沙盒」。触发量降了 88%。

好感度终于会动了。评分规则原来只有五档，而且明写「普通交流 0」，可群里绝大多数互动就是普通对话——实测 1834 次调用几乎全输出 0，187 个人的档案里 165 个停在初始值。现在换成九档，最常见那一档给了 0 到 +0.8 的余地。

历史记录里看得见撤回了，被管理员撤掉的会标出是谁撤的。查询的工具描述也写清了它能按时间范围查，省略条数时给 500 条（上限抬到 2000），不再把一天切成四段查四次。

还可以让她把消息发到任意好友或群了（普通模式）：「把这个发到 xxx 交流群」，撞名会报候选让你挑。开发模式仍然只发管理员。「群聊发完消息后观察窗口」有了自己的开关，覆盖窗口从 5 秒延到 7 秒。

## 子代理

每个子代理现在是挂在父会话下的一条真会话，跑普通回合、历史落库，还能再开一层孙代理（不能更深）。「任务完成」的定义改成「没有活动回合、且名下没有未完成的后台任务」，所以它起了后台命令再结束回合会进等待，命令跑完唤醒它、它再跑完，父会话才拿到结论。消耗计进账本，主会话的 Σ 含整棵树。daemon 重启时上次没跑完的标成「已中断」，给它回复就接着跑。

浮层和后台任务面板补了十几处：里面的字选得动、复制得走，编辑那一步有 diff 和 `+3 -1`，每个工具都有耗时，思考逐字跟着走，而且终于跟着那三个显示开关走了。

## 命令与开关

- `/dev` 和 `/normal` 切到那条车道上的会话；`/session` 把普通、开发两侧合并列出，当前车道排在前面。新增设置「终端集成会话默认模式」。
- `miyu` 和 `miyu dev` 现在打开一条新会话，不再接着上次那条聊。要接着聊用 `/session`。
- 她说话的时候斜杠命令不再一律失灵。回合中开 `/models` `/session` 直接嵌在回合里跑，同一段思考不会被切成好几行小结。
- `/goal` 跑着的时候，输入框右上角常驻一行 `/goal running · 第 3 轮 · 12s`；停下来写 `paused`，受阻写 `blocked`。
- `/sandbox <路径> --allow-read` 多了「只锁写」这一档。`/variant` 改名 `/effort`，旧名留作别名。
- 桌面通知会响一声了，kitty 里点通知能跳回发它的那扇窗。
- shell 集成会跟着 Miyu 一起升级，hook 文件顶上带版本号和内容指纹。
- 同一个会话可以开两个终端界面，两边看到的是同一份实况。
- WebUI 里选中文字右键：解释 / 翻译 / 引用追问 / 搜索 / 复制。表格里能用 `<br>` 换行了。
- 在 [herdr](https://herdr.dev/) 里开 Miyu，侧栏会显示她在干什么。

## 修复

- 模型报错改成说人话。分七档说事，带上这个端点要停多久、供应商自己那句话，不再是一行英文模板加一整坨原始 JSON。claude-code / codex / antigravity 三条中转线也不再谎报「HTTP 429」——它们根本没发过 HTTP 请求，照着那个状态码去查 base_url 只会白费工夫。
- 后台不再攒一堆 `miyu` 僵进程。起 daemon 的那个进程没了，daemon 就跟着退出；Miyu 自己启动的后台服务不受影响。
- Antigravity 被内容策略拦下一句之后，整条会话不会再跟着哑掉；额度出错也不会再让她对某些人长时间一句不回。
- opencode Zen 的免费模型又能用了。
- 会话钉的模型被下架或改名之后会自动退回全局模型池，不再把这条会话锁死、连 `miyu` 都进不去。
- QQ 群里她的引用时灵时不灵，查下来是对端自己发负数消息号又拒收，现在这种情况不会再悄无声息。
- 终端里说话带通配符不再被 fish / zsh 吞掉。她也不能再用 `rm` 删东西了。

## 升级注意

- 要 `miyu daemon restart`。已经开着的终端得重开才用上新前端。
- 原本靠关掉「自然续聊」来一并关掉观察窗口的，升级后观察窗口会重新打开，得单独关一次。
- 手改过表情包搜索条数的配置文件不会自动变，建议自己改成 5。
- 人格功能清单改完要她下一轮才读到。
- DEB 的支持下限这一版才真的生效。以前 24.04 装不上，报的是 `libc6 (>= 2.41)` 不满足，而这个门槛是构建基座定的：以前在 Debian 13（glibc 2.41）里构建，现在换成了 `ubuntu:24.04`（2.39）。

## 下载与安装

附件是 Linux x86_64 的六个安装包。主包自带字体、语义模型、表情、脚本、默认知识库和许可证；语音是可选包，版本要和主包一致，已经装了语音的请在同一条命令里写上两个包。

| 发行版 | 主包 | 可选语音包 |
| --- | --- | --- |
| Arch Linux | `miyu-0.6.1-1-x86_64.pkg.tar.zst` | `miyu-voice-0.6.1-1-x86_64.pkg.tar.zst` |
| Debian 13 / Ubuntu 24.04 LTS 及更新 / Linux Mint 22 | `miyu_0.6.1-1_amd64.deb` | `miyu-voice_0.6.1-1_amd64.deb` |
| Fedora 44 | `miyu-0.6.1-1.fc44.x86_64.rpm` | `miyu-voice-0.6.1-1.fc44.x86_64.rpm` |

```bash
# Arch Linux
sudo pacman -U ./miyu-0.6.1-1-x86_64.pkg.tar.zst

# Debian / Ubuntu / Linux Mint
sudo apt install ./miyu_0.6.1-1_amd64.deb

# Fedora 44
sudo dnf install ./miyu-0.6.1-1.fc44.x86_64.rpm
```

这六个包都在 Arch、Debian 13、Ubuntu 24.04、Ubuntu 26.04、Linux Mint 22.3、Fedora 44 的干净容器里装过一遍，每个都让她真回了一句话。Arch 也可以走 AUR：`miyu` / `miyu-voice` 是二进制包装，`miyu-git` 从源码构建。
